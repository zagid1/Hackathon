# Сценарий ролика (≤ 10 минут)

Цель ролика — показать, что ключевой сценарий работает целиком: **данные → сигналы → карточка → граф → документ**,
и что требования брифа выполнены (воспроизводимость, объяснимость, решение за человеком, пометка синтетики).

**Подготовка перед записью**

* `docker compose up --build` уже выполнен, интерфейс открыт на http://localhost:8501, данные готовы.
* Все сигналы в статусе «Новый» (если нет — `make signals` статусы сохранит; для чистого старта перегенерировать данные: `make data signals`).
* Заранее выбрать 3 сигнала для показа (номера проверить в своём прогоне — при seed 42 они стабильны):
  И2 с объяснением «родственник», И7 (подпись без полномочий), И4 (рост цены допсоглашениями).
* Окна: терминал с репозиторием, браузер с UI, `reports/metrics.md`.

**Советы по записи**

* Разрешение 1920×1080, масштаб браузера 110–125%, чтобы читался текст карточки.
* Терминальную часть записать отдельно и ускорить: генерация и распознавание идут несколько минут.
* Не показывать вкладки/файлы с `injected_schemes` (ground truth) — в UI они и не выводятся.
